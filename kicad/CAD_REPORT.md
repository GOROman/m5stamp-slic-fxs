## 第7ラウンド (2026-10-31): v3.3 全数監査 → v3.4

ユーザーの目視指摘（「端子台が IC に被っている」「シルクがぐちゃぐちゃ」）を発端に、配置品質だけでなくファームウェア整合・電気的妥当性・ネット健全性・製造性・調達整合・極性まで対象を広げた全数監査を実施し、是正版 v3.4 を作成した。

### 監査方法

- 機械監査: pcbnew でダンプした全 160 フットプリント（156 部品＋取付穴4）・全パッド・全シルクテキスト（216 件）を JSON 化し、(1) 実ボディ寸法（F.Fab 実形状。軸型部品はガラス体寸法、電解は内接円で裁定）による本体干渉、(2) シルクのパッド/本/テキスト被り・端はみ出し・最小寸法、(3) 基板↔SKiDL ネットリスト全 375 パッド照合、(4) ファームウェア GPIO とソケット実ネットの全ピン照合、(5) データシート（Ag1171/KS0835F）との電気照合をスクリプトで実施
- 目視監査: 是正後に表裏 3000px レンダリング＋4 象限クロップ＋C10 周辺クロップを生成し全域を目視

### v3.3 の監査結果（重大度別）

| 度 | 件数 | 内訳 |
|---|---|---|
| 重大 | 52 | 本体干渉 1（J2↔U2）/ 本体-パッド干渉 4 / J2 本体の基板端はみ出し 1 / 環状銅箔 46（RJ11 12 + ソケット 28 + その他） |
| 中 | 239 | シルク-パッド被り 84 / シルク-本体被り 102 / シルク同士 53 |
| 小 | 195 | TP プローブ近接 89（列内隣接が大半）/ シルク寸法 80 / J1 端クリアランス 16（設計値 0.33mm）/ その他 |

個別の重大・中項目:

1. **[重大] J2（端子台）本体が U2（74HCT244）のパッド 9〜12 に被る**（重なり 21.85 mm²）。実装不可能。ユーザーの目視指摘どおり
2. **[重大] J2 本体が基板下端から 0.7mm はみ出し**
3. **[重大] RJ11 パッド環状銅箔 0.10mm**（パッド 1.1×1.6 / ドリル 0.9、ピッチ 1.27mm）— JLCPCB 2層1oz の絶対最小 0.18mm 未満（Issue #6）
4. **[重大] Stamp ソケット環状銅箔 0.15mm**（パッド 1.0 / ドリル 0.7）— 同上未満
5. **[中] シルク全般**: J_3/J_4/MOD_A/MOD_B/U1 のリファレンスが非表示、J1 リファレンスが反転＋基板外、取付穴リファレンスが基板外、TP ネットラベルが 0.85mm 高（最小 1.0mm 未満）、警告文が裏面パッド列に被る等、239 件
6. **[中] PD ダイオードの論理レベル**: PD ピンを 1N4007 経由で引き下げると Low が約 0.67V となり、Ag1171 の PD VIL(max) 0.5V を超過。データシート推奨トポロジではあるが紙規格外で、PD 機能が silently に効かない恐れ（現ファームウェアは PD_EN を常時無効のため潜在）
7. **[中] 電源予算**: 最悪約 1.5A（SLIC リング 480mA＋オフフック 400mA※データシート DC 特性、リレー 111mA、Stamp WiFi ピーク約 500mA 等）に対しポリヒューズ保持 2A（40℃ で約 1.7A にディレーティング）。DESIGN の 5V/3A 電源前提とは整合するが、通常の USB 2.0 ポート（500mA）では電圧低下する旨の明記が必要
8. **[小] リレードライバ余裕**: 2N7002 の Rds(on) 最大 7.5Ω（Vgs 5V）→ コイル電圧最悪約 4.0〜4.25V > G5V-2 動作保証 3.75V で適合だが余裕は薄い。実機でコイル電圧を実測推奨

### 電気・整合の検証結果（問題なしを確認したもの）

- **ファームウェア GPIO 全ピン照合: 13 ピン全て一致**（MON_A=GPIO1, MON_B=2, LED=4, TONE=6, SHK_A=7, RM_A=8, FR_A=9, SHK_B=10, RM_B=11, FR_B=12, SEL_A=13, SEL_B=14, PD_EN=15）。基板↔SKiDL ネットリストは 375 パッド中、既知の J1 `S1`↔`SH` 命名差のみ
- U2 (74HCT244) 全 20 ピン実チップピン配置と一致（pin3 2Y4 の意図的 NC、pin17 2A4=GND 含む）。HCT の VOH 約 4.4V > SLIC 制御入力 VIH(min) 3.5V で、3.3V 直結では不足する＝レベル変換の存在理由を確認
- SHK 分圧: SHK_33 = 2.87V > ESP32-S3 VIH 2.475V（余裕 0.40V）。Q5/Q6（HOOK LED バッファ）のゲートは分圧前 4.47V 駆動で適合
- LED 電流は全 9 個を再計算し適合（D2 3.0mA / D3 2.8mA / HOOK 2.0mA / RING 1.9mA / LINK 2.0mA）
- KS0835F 標準接続図との照合: VR/VX 結合 100nF、+VDC バルク 470µF/ポート、CLI バイアス 27K（推奨 20〜39K）、保護ブリッジ＋BZT03C82＋P3100SC の構成すべて一致。**RM 外付けコンデンサは不要**（Ag1171/KS0835F 両資料とも RM は純粋な論理入力）
- ネット健全性: 1ピンだけのネット **ゼロ**。+5V 17 員 / +3V3 5 員 / GND 75 員、全電解コンデンサの＋極は正電源側、全ダイオード（ブリッジ・還流 K=+5V・TVS・PD）の向き適合
- 極性シルク: 電解の「+」印、DO-41 の K マーカー 14 件、LED のカソードブラケット、モジュール 1 番ピン円、RJ11 1 番角パッドは全て判別可。**U2 の 1 番ピンマークのみ不足** → v3.4 で追加

### Issue #4〜#7 の取り込み

- **#6（RJ11 環状銅箔）**: 是正対象として v3.4 で修正（下記）。実ジャック（uxcell、2026-11-01 到着予定）のピン実測で最終ドリルを確認すること。ピン対角が 0.72mm 以下なら ドリル 0.75 で環状 0.21mm にできる
- **#4（PlatformIO/Arduino API 不整合）**: ファームウェアに LEDC 互換シム（core 2.x/3.x 自動切替）を導入し、platformio.ini を `espressif32@7.0.1` にピン留め、CI に実ターゲットビルド job と両分岐のホストコンパイルを追加。ホストテストは両分岐ともパス。実 `pio run -d firmware`（espressif32@7.0.1 / core 2.0.17）も **SUCCESS**（esp32s3 イメージ生成を確認、2026-10-31）
- **#5（単体リング試験後の誤発呼）所見**: コード確認済み。EX_RING_TEST の終了が EX_RINGING 経路と違いフック状態を同期せず toIdle() するため、RING_TRIP_MS(10) < HOOK_DEBOUNCE_MS(15) の条件で受話器を上げた端末をオンフック扱いし、次ループで相手を呼び出してしまう。修正方針: toIdle で rawHook を pending 扱いにするか EX_WAIT_ONHOOK へ遷移。基板の問題ではないため本ラウンドでは所見のみ
- **#7（40ms DTMF 取りこぼし）所見**: DTMF_N=205 @8kHz = 25.6ms 窓＋2 窓連続確認では 40ms トーンは位相により取りこぼす（Issue のホストテストで 131/205）。70ms では 0/205。FAX/電話機の実用 DTMF は 70ms 以上が標準的なため、要求仕様として「最小トーン長 70ms」を明記するのが妥当。基板の問題ではないため所見のみ
- 付随観察: `tests/test_hardware.py` に既存の失敗 2 件（存在しない J7 ジャンパ参照、SKiDL↔保存ネットリストの参照番号ドリフト）。本ラウンドの変更前から失敗しており、基板の正は保存ネットリスト（基板と 375 パッド一致を検証済み）。テスト側の追随は別途

### v3.4 の是正内容

- **部品移動**（確定済み設計判断を維持）: U2 を dy −5.5、C6 を dy −4.7（U2 pin20 への距離は 4.4→約 3.1mm に改善）、K1 を dy −1.2、J2 を dy −1.0（筐体が基板内に収まり U2 と 2.0mm 離隔）。パスコン近接配置・C10 裏面・LED 上端・J1 端クリアランス 0.33mm はすべて不変
- **パッド拡大**: RJ11 全パッド 1.17×1.9mm / ドリル 0.8 → 環状 0.185mm（≥0.18 下限）。隣接パッド間 0.10mm は JLCPCB マスクブリッジ最小値ちょうど（ピッチ制約のトレードオフとして明記）。Stamp ソケット 1.1×1.1 → 環状 0.20mm
- **部品変更**: PD ダイオード U79/U106 を 1N4007 → **1N5819**（ショットキー、DO-41 同一フットプリント）。PD Low は約 0.35V となり VIL 規格内。SKiDL・BOM も同期（1N4007 は 10 個に、1N5819 行を追加）
- **シルク全面再配置**: 制約ソルバで 225 テキスト（全リファレンス 159＋TP ラベル 34＋K マーカー 14＋基板ラベル 11＋新規マーク 3＋警告 4）を、パッド/本体/取付穴頭/他テキストへの干渉ゼロ・基板内・0°/90° の条件で再配置。TP ラベルは 1.0mm 高に拡大、LED ラベル（HOOK/RING/LINK）は 1.0mm 高・線幅 0.15mm に拡大、U2 に 1 番ピンマーク「1」、J2 に「+」「−」を追加、非表示だった 5 部品のリファレンスを表示化。読み捨てになった「M5StampS3 SOCKET」ラベルは U2 移動に伴い配置不能となったため削除（U1 リファレンスで代替）
- **裏面警告文**: 旧 3 行を削除し、h1.8 の 4 行（LOCAL LINE ONLY / DO NOT CONNECT TO PUBLIC / NETWORK (PSTN) - CAUTION / RING VOLTAGE UP TO 135Vp-p）を裏面上部のパッド列のない帯（y 8.0/12.5/19.5/27.2）に再配置。C10 リファレンスはチップ直下の可読位置に確定
